# Code of conduct

SceneAxi follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

To report a conduct concern privately, use the [GitHub Security Advisory route for Vhailors/sceneaxi](https://github.com/Vhailors/sceneaxi/security/advisories/new). The maintainers handle reports through this route.
