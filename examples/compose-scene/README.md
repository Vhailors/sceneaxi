# Compose a scene

This example reconstructs two checked-in Sculpt Intakes, composes one instance of each into a two-object scene through the public `@sceneaxi/authoring-core` package-root API, and prints the deterministic scene digest. It reads fixtures from this repository and makes no network calls.

From the repository root, run:

```sh
pnpm build
node examples/compose-scene/run.mjs
```
