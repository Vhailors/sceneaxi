# @sceneaxi/catalog-game

Dormant game-asset storefront app. Speaks **only** `@sceneaxi/schemas` catalog
contracts (Catalog Item + fail-closed pipeline stub). No storefront UI, no
marketplace activation, no spend.

Policy SoT stays on factories-helpers [#47](https://github.com/Vhailors/factories-helpers/issues/47)
and [#48](https://github.com/Vhailors/factories-helpers/issues/48). Commerce
fields remain inert until tier-6b holds open. This stub remains
topology-neutral; the locked storefront topology is recorded in the canonical
product spec ([#1](https://github.com/Vhailors/sceneaxi/issues/1)).
