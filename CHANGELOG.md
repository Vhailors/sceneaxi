# Changelog

Notable changes are recorded here for users of SceneAxi. This changelog follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added
- Added a deterministic in-memory Kids activity with curated worlds, bounded pieces, undo, reset, and play controls.
- Added bounded project-asset imports with validation, previews, provenance, contained materialization, and review-only hot reload.
- Added authoring proposals for transforms, animation, physics, and reusable scene content.
- Added local desktop project workflows, hierarchy editing, multi-selection, and static Web export.
- Added fixture-backed OpenRouter adapter plumbing with exact model pinning and no ambient network access.

### Changed
- Expanded the Linux desktop authoring workflow and local assistant build support.
- Kept Kids isolation fail-closed across third-party model routes, network destinations, catalogs, commerce, and external data planes.
